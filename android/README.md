# Azeroth Survivors Android

为 Android 12 及以上手机制作的社区 APK，保留 Aethus 原作的玩法、中文资源和合作入口。当前版使用官方 **0.126.0 / 3e72472a** 网页核心；官方原始资源快照保留；第四版仅在打包副本中调整原生刷新按钮的 UI 尺寸。

这版仍是网页核心的安卓封装，不是从原作 Rust 源码编译的原生安卓游戏。APK 包含完整资源，约 874 MiB；画面和运算在手机本地执行。合作需要联网。

## 安装与启动

已构建版本见 [Android 第四版 Release](https://github.com/al90slj23/azeroth-ports/releases/tag/android-v0.126.0-r4)，含 APK、SHA-256、实际游戏画面与验证摘要。

1. 将 `dist/AzerothSurvivors-0.126.0-android.4-universal.apk` 传到手机安装。
2. 更新 Android System WebView 和 Chrome。
3. 打开 App，点“开始游戏”。内置模式会先检查可用的 WebGPU 适配器和设备。
4. 内置模式无法启动时，使用“Chrome 模式”。它仍读取 APK 内的本地资源。
5. 游戏横屏运行，使用原作触控界面。Chrome 模式首次触控后会尝试进入全屏。

Android 版本满足要求不代表每种 GPU 或驱动都能运行。目标是现代主流 Android 手机；没有宣称所有机型兼容或保证帧率。无 Google Play 的手机也可安装 APK，但需要自行具备支持 WebGPU 的 WebView 或 Chrome；Chrome 模式只寻找已安装的 Chrome 稳定、Beta、Dev、Canary 包。

使用 Chrome 模式时请保留本地资源服务。退出后可以从启动页或通知点“停止游戏资源服务”。该服务仅绑定 `127.0.0.1:47615`，不对局域网提供游戏文件。Chrome 自身的地址栏可能出现；没有绕过网站关联验证来伪装 TWA。

## 安卓第四版：原刷新按钮放大

移除试作的额外选卡工具栏，直接点击原来的三张卡片。原生红底金边“重抽”按钮、文字、剩余次数／金币费用和 R 标记等比放大为两倍，实际点击范围随原生布局一起扩大。按钮由游戏重新绘制，不拉伸低清图片，也无需替换成 AI 图片。

改动限定在官方 0.126.0 WASM 的刷新按钮创建函数内，共 28 个布局／字体常量；免费次数、金币扣除、随机结果、禁用判断及原有输入逻辑保留。打包脚本严格校验官方完整文件、函数与每处指令，版本不符即停止；原始快照始终保留。第三版的 Boss／HUD 缩放和快捷浮窗暂停功能继续保留。

验证记录见 `evidence/verification-r4.json` 和 `evidence/native-reroll-qa-summary.json`。已完成桌面 Chromium 的游戏画面、鼠标和菜单模式触控回归；普通模式原生触摸与真实安卓仍需真机确认。

## 安卓第三版修复

打开“快捷”浮窗时暂停本机游戏，收起后恢复；原作本来已暂停时，开闭浮窗会保留原暂停状态。暂停只作用于游戏引擎的帧和单调时钟，浮窗及温度读数可继续使用；恢复时扣除浮窗暂停时长，避免对局突然追赶时间。联机时其他玩家及远端房间不随本机冻结。

第三版增加独立的HUD更新标记，修复旧版遇到已保存默认100%或旧75%迁移值时未继续缩小的问题。首次第三版启动将这些默认配置设为50%；其他自定义比例保留。HUD滑块范围扩展为50–100%，界面读取实际配置，不以旧面板记录推断已生效。这仍是原作整体HUD缩放，同时影响首领条、时钟和技能等HUD。

实际游戏回归已验证同一醒着的守卫血条在100%与50%下宽高减半（780×20→390×10 CSS像素）；角色死亡面板遮住中部，两端和厚度可见。快捷浮窗开10秒时计时/HP/怪物动作不变，关闭1秒后计时仅加1秒；原有游戏菜单暂停也能保留。这是桌面Chromium安卓触控模拟回归，仍需真机确认。

第三版安装包和实际游戏验收记录于 `evidence/verification-r3.json`；第二版证据保留。

## 安卓第二版改进

游戏内右上角默认显示可拖动的“快捷”入口。常用操作为角色、天赋、暂停以及敌方／全部／友方血条切换，对应原作 C、N、Esc、V、Ctrl+V、Shift+V。血条按钮是切换操作，不假设当前显示状态。

菜单画布内选“拖动列表”，可直接上下拖动内容；选择“查看详情”后点底部技能栏或角色装备，会将鼠标悬停保持在那里供原作显示提示。屏幕上始终有“恢复正常操作”，战斗前切回以使用原作摇杆和多指操作。仍需要显式选择模式；没有自动识别所有菜单。左侧独立技能列尚未观察到提示，暂可从底部对应技能查看。

已修正固定画布与手机像素密度不一致时的输入坐标，保留原始触摸事件和多指身份。首次更新时，只有未自定义过 HUD 大小的配置会设为75%；已有设置保留。第二版浮窗提供70–100%调节；第三版扩展为50–100%。它同时缩放首领血条、时钟、技能等整体 HUD，原作封闭核心还不能单独改变首领条。

性能页提供节能／均衡／清晰和真实3D渲染比例50–100%、视距、样式与特效调节。原作部分设置要求重启，选择后会保存，下一次启动生效；不会中断当前对局。手动重启有二次确认。单独调整HUD或某一滑块仅保存相应参数，保留其他游戏设置。

内置模式通过Android系统显示电池温度和热状态，无新增权限。温度有更新延迟，不是CPU/GPU温度；系统不提供时及Chrome模式显示不可用。节能降低图形负载，不保证手机不发热。

已为简体中文增加46个经验／探索／升级／掉落消息模板，40个区域显示名、7个地图显示名。按实测原作 `rogue.language=zh` 加载独立资源；其他语言保留原始资源。切换语言后请返回主菜单再重启，以替换已载入内存的消息和地图表。这是针对已定位遗漏的补译，尚未覆盖游戏所有英文内容。消息格式参数、区域ID、地图路径和坐标保持不变。

## 存档和联机

内置模式和 Chrome 模式的浏览器存储独立，使用游戏内 Options → Saves 导出／导入迁移。内置模式的导出通过 Android 系统文件选择器保存，导入使用系统文档选择器；这两个流程仍需真机确认。更新 APK 时保留同一签名，不要通过卸载来更新，以免丢失 App 私有存档。

合作入口沿用原作。安卓适配脚本仅将本机 `/coop` WebSocket 地址改为官方 `wss://wow.aethus.pl/coop/...`；官方返回的游戏中继地址保持不变。所有玩家需核对相同游戏版本，当前为 **0.126.0**。之前的 Mac 0.123.0 包未在本次任务中更新。

官方 0.126.0 更新说明包含中文、日文、韩文的输入法改进。本 APK 已包含新增 `ime.js` 模块和官方中日韩字型，但尚未在真实安卓键盘上验证中文名称输入。

## 实现与安全边界

- Android 原生启动页、横屏与全屏处理；硬件加速 WebView。
- 启动时真实请求 WebGPU adapter/device，失败时提供明确提示和 Chrome 入口。
- 保留原作 Android UA 与 `pipe_warm=0`、`pbr_lite=1` 手机图形预设。
- APK 内压缩资源直接通过 AssetManager 流式读取，不必先解压成第二份资源包。
- HTTP 支持 Range、ETag 与更新后缓存重新验证。
- JavaScript 桥接只有图形检测、受限存档导出和电池温度／系统热状态的只读快照，不提供任意文件、命令或应用执行接口。
- 保持 TLS 验证；明文网络仅允许 loopback；外部页面不能嵌入桥接窗口。
- 不含广告、账号系统或额外分析 SDK；原作的官方网络请求仍由原作核心执行。

## 构建

需要 Python 3.11+、JDK 17、Google Android SDK API 35 和 Build-Tools 35.0.0。当前脚本直接使用 javac/d8/aapt2/apksigner，不依赖 Gradle。

`scripts/sync_official.py` 下载同一标记的原始核心、动态模块、变化资源及索引，验证 WASM 编译和导入，生成 `assets/latest-web-core/core-manifest.json`。完整的大型资源基底来自已保留的官方 Mac 包 `Contents/Resources/www`，只读使用，不修改 Mac App。

```sh
python3 scripts/build_apk.py \
  --sdk /path/to/android-sdk \
  --java-home /path/to/jdk17 \
  --web '/path/to/Azeroth Survivors.app/Contents/Resources/www' \
  --core /path/to/verified-web-core
```

输出有 APK、SHA256SUMS.txt 和 build-manifest.json。签名密钥仅保存在 `.private/`，不放入 APK 或源码分发包。要保持后续更新兼容，需保留此目录；不要公开它。
