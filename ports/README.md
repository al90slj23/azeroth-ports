# 封装优化

这一板块继续维护可安装、可游玩的社区版本。两个平台保留原来的源码、构建入口和发布方式：

| 平台 | 当前核心／版本 | 源码与构建说明 |
|---|---|---|
| Android 12+ | 官方核心 0.126.0，社区第四版 `0.126.0-android.4` | [Android](../android/README.md) |
| macOS / Apple Silicon | 官方核心 0.123.0 | [macOS](../macos/README.md) |

Android 第四版安装包见 [GitHub Release](https://github.com/al90slj23/azeroth-ports/releases/tag/android-v0.126.0-r4)。平台核心版本尚未统一；上述版本记录不代表所有机型、普通触控或跨平台联机都已通过真机验收。

## 当前重点

- 手机 UI 和触控：保留卡片直接选择，优化原控件的尺寸、命中区域、列表拖动和详情提示，并在真机上确认普通触控。
- Boss／HUD：继续改善手机屏幕上的比例与布局，区分整体 HUD 缩放和独立首领血条调整。
- 离线体验：核对完整本地资源和断网单机流程；原作还包含 `/presence` 状态上报，当前版本不能称为只有合作模式才有外网请求。
- 合作兼容：核对核心版本、大厅／房间连接与同步行为；同机双程序或桌面仿真不能替代实体 Windows 电脑与 Android 手机之间的验证。

## 与逆向研究的衔接

另一板块是 [REA 逆向研究](../reverse-engineering/README.md)，负责分析原始二进制、资源与运行行为。原始 Windows `0.102.3` 可作为研究基线，不能视为当前 Android 或 macOS 核心。

这里的导航不会搬动 `android/`、`macos/`，也不会改变构建、签名、包标识或存档路径。逆向研究结论进入发布前，应固定对应的原始文件与 SHA-256，使用带版本／指令校验的可重现补丁，并完成相应回归；原始快照保留，试验产物与正式包分开。
