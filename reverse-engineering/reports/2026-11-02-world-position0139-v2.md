# 0.139.0 自然位置采样 v2

修正了原件函数 13563 前十二次试取的区域半径计算：逐项 binary32 乘法、加法后开方。旧版误用了函数 50441 的 binary64 平方和路径。旧十件源码、80 次原件数据和独审拒绝结论完整保留；其输出恰好一致不能支持错误规则。8740 本身仍使用 50441，修正版没有改变这条路径。

本次独立期望先冻结，再执行未修改函数及其完整 callee 的原件：85 次返回全部一致（63 次直接 8740、22 次直接 13563），882 个宿主导入全部拒绝，实际宿主调用为零。前 80 个输入与旧批次相同，新增 5 个实地图首试 clamp 反例全部支持修正版，并与旧错误参考的 XYZ 不同；最终 RNG 一致。6 次 pilot 另列，不累计到正式 85 次。异作者复核待完成。

期望使用从 139 原始地图资源独立生产的 canonical 数据。目标函数接收健康 v2 的真实 Elwynn 世界上下文，显式控制玩家位置、速度、RNG 和路径视图；不读原件内存生成期望。2318 个世界源区间（5,950,608 字节）前后摘要一致；85 份完整 Game 2592 字节中只有 RNG16 字节允许改变并独立比对。XYZ 输出为显式 16 字节区，末 4 字节 A5 和前后各 16 字节 canary 均保留。None 路径 backing 未被懒读；实际路径生产者、世界 Rc 所有权与 primary-present 域仍未知。模型试取/缩圈次数仅属模型诊断。

准备过程有一次冗余 wasm-validate 在 45 秒预算后被 finally 终止并等待，目标函数调用为零；旧 builder 没有预先记录 validator PID，该限制和精确命令后查无进程一并保留。新 builder 使用与已验证原件私有导出模块逐字节相同的模块（仅 export section 有变动），复用其静态有效性证据，并由本次 Node 重新编译；不转移任何旧模型行为验收。正式原件进程 PID/PGID 60231，exit 0，二者已消失，8.108 秒，256 MiB 上限，111,804,416 字节峰值。

该批只验证受控位置采样。没有原生 EXE 执行、完整 1108、自然四敌人组合或完整游戏验收，不修改安装包和存档。
